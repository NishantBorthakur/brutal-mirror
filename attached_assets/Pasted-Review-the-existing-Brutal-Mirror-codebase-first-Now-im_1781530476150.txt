2. REPLIT DATABASE SETUP
==================================================

Add/use Replit PostgreSQL database.

Create database tables for:

A. users / profiles
Fields:
- id serial or uuid primary key
- replit_user_id text unique not null
- email text
- display_name text
- credits_balance integer not null default 0
- free_credits_granted boolean not null default false
- created_at timestamp default now()
- updated_at timestamp default now()

B. credit_transactions
Fields:
- id serial or uuid primary key
- user_id references users/profiles(id)
- type text not null
- credits integer not null
- balance_after integer not null
- reason text
- metadata jsonb default '{}'
- created_at timestamp default now()

Transaction types:
- free_grant
- usage
- purchase
- refund
- adjustment

C. roast_logs
Fields:
- id serial or uuid primary key
- user_id references users/profiles(id)
- category text
- intensity text
- personality text
- refinement_mode text
- input_preview text
- input_tokens integer default 0
- output_tokens integer default 0
- total_tokens integer default 0
- credits_used integer default 1
- success boolean not null default true
- error_message text
- created_at timestamp default now()

Create migrations or schema files if the project uses Drizzle/Prisma/SQL files.

5. CREDIT RULES
==================================================

A roast or refinement costs 1 credit.

Rules:
- Fresh roast = 1 credit
- Make it sharper = 1 credit
- Make it funnier = 1 credit
- Make it more professional = 1 credit

Deduct credits only after successful AI response and valid JSON parsing.

Do not deduct credits if:
- user is not logged in
- user has zero credits
- validation fails
- AI API fails
- backend fails
- AI returns invalid JSON

6. UPDATE /api/roast
==================================================

Update POST /api/roast to require authenticated user.

Backend flow:
1. Verify Replit Auth user.
2. Get or create profile.
3. Check credits_balance.
4. If credits_balance <= 0:
   return error:
   {
     "error": "OUT_OF_CREDITS",
     "message": "You are out of credits."
   }
5. Generate AI roast.
6. Validate AI JSON response.
7. Deduct 1 credit in database.
8. Insert credit_transactions row:
   type: usage
   credits: -1
   reason: "Roast generation" or "Roast refinement"
   balance_after: updated balance
   metadata: category, intensity, personality, refinementMode
9. Insert roast_logs row with:
   user_id
   category
   intensity
   personality
   refinement_mode
   input_preview
   token usage if available
   credits_used: 1
   success: true
10. Return:
   - AI result
   - updated credits balance

If AI fails:
- Insert roast_logs row with success=false if possible.
- Do not deduct credit.
- Return clean error.
