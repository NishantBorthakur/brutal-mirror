4. BACKEND ENDPOINT: CREATE RAZORPAY ORDER
==================================================

Create endpoint:

POST /api/billing/create-order

Requires logged-in Replit Auth user.

Request body:
{
  "packId": "starter" | "value" | "power"
}

Backend behavior:
1. Verify logged-in user.
2. Validate packId against server-side pack config.
3. Do not trust price or credits from frontend.
4. Create Razorpay order using Razorpay server SDK.
5. Store order in payment_orders table with status = created.
6. Return:
   {
     orderId,
     amount,
     currency,
     keyId,
     packId,
     credits
   }

Important:
- Pack prices and credits must be defined server-side.
- Frontend must not be able to manipulate price or credits.

6. BACKEND ENDPOINT: VERIFY PAYMENT
==================================================

Create endpoint:

POST /api/billing/verify-payment

Requires logged-in Replit Auth user.

Request body:
{
  "razorpay_order_id": "...",
  "razorpay_payment_id": "...",
  "razorpay_signature": "..."
}

Backend behavior:
1. Verify logged-in user.
2. Fetch payment_order by razorpay_order_id.
3. Ensure the order belongs to logged-in user.
4. Ensure order is not already paid/verified.
5. Verify Razorpay signature server-side using:
   razorpay_order_id + "|" + razorpay_payment_id
   and RAZORPAY_KEY_SECRET
6. If signature is invalid:
   - mark payment_orders status = failed
   - return error
7. If signature is valid:
   - mark payment_orders status = verified or paid
   - store razorpay_payment_id and signature
   - add credits to user profile credits_balance
   - insert credit_transactions row:
     type: purchase
     credits: pack credits
     balance_after: updated balance
     reason: "Razorpay credit purchase"
     metadata:
       razorpay_order_id
       razorpay_payment_id
       pack_id
       amount_in_paise
   - return updated credits balance

Important:
- Make this endpoint idempotent.
- If the same payment is verified twice, do not add credits twice.
- Return existing successful result if already verified.
