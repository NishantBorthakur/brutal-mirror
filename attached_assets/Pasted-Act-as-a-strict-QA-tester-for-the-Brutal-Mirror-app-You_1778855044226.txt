Act as a strict QA tester for the Brutal Mirror app.

Your job is to test the latest version of the app end-to-end and identify bugs, UX issues, broken logic, missing output fields, console errors, mobile layout problems, and backend/API problems.

Do not modify the app yet unless explicitly asked. First test and report issues clearly.

==================================================
QA OBJECTIVE
==================================================

Test whether Brutal Mirror works as a polished premium AI roast/report product.

The app should support:
- Category selection
- Intensity selection
- Roast Personality selection
- Example chips
- AI roast generation
- Viral one-liner
- Roast Report scores
- Result tabs
- Before vs After section
- Share card
- Copy buttons
- Regeneration buttons
- History storage
- New Roast reset behavior
- Validation handling
- Mobile responsiveness
- No horizontal scrolling
- Clean error handling

==================================================
GENERAL QA CHECKLIST
==================================================

Check the following first:

1. App loads without crashing.
2. No console errors on initial load.
3. UI is mobile-first and responsive.
4. No horizontal scrolling on mobile.
5. Buttons do not overflow.
6. Text wraps properly in result cards.
7. Loading states appear correctly.
8. API errors are displayed cleanly.
9. Old history items do not break the app.
10. Copy buttons work.
11. New Roast button clears the input and resets the result.
12. Result section scrolls into view after generation.
13. History stores original prompt, category, intensity, personality, date/time, and result.
14. Result tabs work correctly.
15. Score bars render correctly.
16. Regeneration buttons call the backend and update the output.
17. Usage limit, if implemented, does not incorrectly count failed attempts.
