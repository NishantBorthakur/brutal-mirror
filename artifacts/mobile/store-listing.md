## Graphic Assets Required

All assets must be provided before submitting. Specs below:

### App Icon
- **Size:** 512 × 512 px
- **Format:** PNG, 32-bit (with alpha)
- **File:** `assets/images/icon.png` (replace with 512×512 version)
- **Note:** Current icon is used for all platforms. Ensure it is exactly 512×512 with no rounded corners — Play Console applies rounding automatically.

### Feature Graphic *(required)*
- **Size:** 1024 × 500 px
- **Format:** JPG or PNG, no alpha
- **Design guidance:** Dark background (#0a0a0a), electric purple (#8b5cf6) accent. Show the app name and a one-line hook. No device frames needed.

### Screenshots *(min 2, max 8 per device type)*

Capture from an Android phone (1080×1920 or similar). Recommended set:

| # | Screen to capture | What it shows |
|---|---|---|
| 1 | Roast form (filled in) | Input + category/intensity/personality selectors |
| 2 | Roast result — top section | The roast text + report ID header |

| 4 | Viral One-liner card | Shareable quote + copy button |
| 5 | Rewritten version section | The improved text |
| 6 | Roast Vault | History list with search bar |
| 7 | Settings screen | Default preferences |

**Screenshot tips:**
- Use a real device or emulator with status bar hidden
- Capture at the highest resolution available
- Avoid capturing during loading states

## EAS Build & Submit Commands

```bash
# 1. Make sure you are in artifacts/mobile
cd artifacts/mobile

# 2. Production build (AAB for Play Store)
eas build --platform android --profile production

# 3. Submit to Play Store (internal track first)
#    Requires google-service-account.json in artifacts/mobile/
eas submit --platform android --profile production

# 4. Or submit a specific build by ID
eas submit --platform android --id <build-id>
```

### Before submitting, you need:
- [ ] `google-service-account.json` in `artifacts/mobile/` (download from Google Cloud Console → Service Accounts, with Play Developer API access)
- [ ] Feature graphic (1024×500 px) uploaded in Play Console
- [ ] At least 2 screenshots uploaded in Play Console
- [ ] Privacy policy URL live and accessible: https://brutal-ai-web.replit.app/privacy
- [ ] Content rating questionnaire completed in Play Console
- [ ] Data safety form completed in Play Console
- [ ] App reviewed once on the internal testing track before promoting to production
